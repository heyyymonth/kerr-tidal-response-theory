# Claims and evidence

Status at the repository foundation, 13 November 2026. A passing algebra check
is not a matched-response calculation. The unchanged scientific records contain
32 baseline checks, 18 curvature checks, and 16 Ricci-component checks.

| Statement | Status and supporting evidence | Boundary of the claim |
|---|---|---|
| The normalized Ernst equation admits Schwarzschild and Kerr. | Exact symbolic identities in [baseline.json](results/baseline.json), reproduced by [verify_baseline.py](verify_baseline.py). | Background consistency, not a solved tidal boundary-value problem. |
| The printed complex normalization and arbitrary-holomorphic seed prescription fail the stated substitutions. | Explicit residuals in the same baseline record; published Eqs. (2.11), (6.7) visually rechecked. | Formula-level counterchecks do not refute the paper's physical conclusion. |
| Bounded static distortion excludes separated prolate decaying modes in a finite sum. | Analytic argument in [README](README.md#3-recover-the-known-static-seed-argument); low multipoles checked symbolically. | Known result; infinite sums need convergence control. Weyl-spherical seed amplitudes are different parameters. |
| The mixed second variation has a source generated by the two first-order fields. | Exact arbitrary-function identity in [baseline.json](results/baseline.json). | The first-order tidal fields and the driven Kerr solution have not been computed. |
| The reflected stationary curvature polynomial is consistent with the local vacuum identities. | Independent frame contraction and 16 Ricci-component checks in [verify_mixed_horizon.py](verify_mixed_horizon.py). | The vacuum equations are imposed in the construction. This is not a check of a complete global mixed Kerr metric. |
| Exact Schwarzschild and two nonzero-spin Kerr points give the expected curvature. | Controls in [mixed-horizon.json](results/mixed-horizon.json). | Two points are implementation controls, not a general proof by sampling. |
| For fixed nonzero decaying amplitude and finite growing amplitude, the static scaled logarithmic limit is positive. | Exact static derivation in [mixed-horizon.md](mixed-horizon.md) and symbolic limits. | The full published prefactor is not reproduced; the zero-amplitude limit is not uniform. |
| The same leading logarithmic limit holds in the declared rotating family. | Conditional asymptotic argument in [mixed-horizon.md](mixed-horizon.md#3-the-two-rotating-branches), supported by exact identities. | Requires reflection symmetry, the specified vacuum family, fixed nonzero Kerr-seed parameter, and fixed amplitudes. It is not a black-box symbolic proof. |
| Finite applied amplitude cannot remove that local obstruction. | Leading asymptotic dominance; the static mixed derivative itself diverges. | No global event-horizon classification, nakedness, or completeness theorem. |
| Nonlinear Schwarzschild vanishing results already exist. | Primary papers and scope recorded in [the literature audit](docs/literature-audit.md). | These are prior results, not this project's discoveries; rotation requires a separate argument. |
| The aligned order eta_2 eta_4 chi^2 mass-quadrupole response vanishes. | **Conjecture only.** Angular allowance is checked; no coefficient is defined by completed matching or calculated. | Tensor basis, identifiable combination, horizon/axis boundary conditions, parameter conventions, and external matching remain unresolved. |
| This particular mixed Kerr channel is novel. | **Not established.** A bounded primary-source audit found a broader documented gap. | Search non-detection is not proof of priority or completeness. |
| The inherited evidence can be reproduced. | [verify_reproduction.py](verify_reproduction.py) and [reproduction.json](results/reproduction.json). | Reproduction checks identities and record integrity, not physical calibration or scientific peer review. |

The research-history discussion of stellar-cluster transport is contextual. No
